# Loan Default Risk Analysis Dashboard

## Overview
This Power BI dashboard provides comprehensive analysis of loan defaults, borrower demographics, and financial risk indicators.

## Dashboard Pages
### 1. Loan Default & Overview
- Loan Amount by Purpose
- Average Income by Employment Type
- Default Rate Analysis
- Age Group Analysis
- Year-wise Default Trends

### 2. Applicant Demographics & Financial Profile
- Credit Score Analysis
- Marital Status Insights
- Education-based Loan Distribution
- Mortgage & Dependents Analysis

### 3. Financial Risk Metrics
- YoY Loan Growth Analysis
- YoY Default Trend Analysis
- Income Bracket Risk Assessment
- Credit Score & Marital Status Analysis

## Tools Used
- Power BI
- DAX
- Excel

## Business Impact
Identified borrower segments with higher default risk and provided insights for better credit risk assessment and lending decisions.
